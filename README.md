# habitatPredictR

<!-- badges: start -->

<!-- badges: end -->

The goal of habitatPredictR is to automate the process of converting
outputs from state-and-transition simulation models into habitat
predictions.

## Installation

You can install the development version of habitatPredictR from
[GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("alberta-conservation/habitatPredictR")
```
